# 🌱 Plant Disease Detection Using Deep Learning

## 📖 Project Overview
This project aims to detect plant diseases from leaf images using Deep Learning and Computer Vision techniques. The goal is to help identify plant diseases quickly and accurately through image-based analysis.

## 🎯 Objectives
- Detect diseases from plant leaf images.
- Classify healthy and diseased plants.
- Provide disease information and recommendations.
- Build a user-friendly web application for predictions.

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Streamlit

## 📂 Dataset
PlantVillage Dataset
